# ✈️ Sky Duel: Fighter Jet Dogfight Game

A top-down fighter jet dogfight game that runs in any browser. Pick your jet, dodge enemy fire, fire homing missiles and take down a boss every 5 waves.

**▶ Play now:** https://alphazolo12200-tech.github.io/sky-duel-jet-dogfight/

Works on phone and desktop. No install, no sign-up, no downloads.

## Features

- **4 selectable jets** with different speed, turning, armor, fire rate and missile count
- **Enemy variety:** grunts, fast scouts, heavy bombers with spread shots, and a boss every 5th wave
- **Weapons:** twin cannons and homing missiles
- **Pickups:** repair and missile packs dropped by destroyed enemies
- **Living world:** scrolling islands, drifting clouds and a day/night cycle
- **Sound effects** generated in the browser (press N to mute)
- **Adjustable game speed:** Relaxed, Normal or Fast
- **Touch and keyboard controls**

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Turn | A / D or Left / Right | Drag toward a point |
| Boost | W or Up | n/a |
| Fire cannons | Space | Auto-fire while dragging |
| Fire missile | M | MISSILE button |
| Mute | N | n/a |
| Back to menu | Esc | Tap after game over |

## The Jets

| Jet | Style | Hull | Missiles |
|---|---|---|---|
| Falcon | Balanced all-rounder | 8 | 10 |
| Viper | Fast and agile, lighter armor | 6 | 8 |
| Titan | Heavy armor, slow turns | 14 | 14 |
| Ghost | Rapid fire, light armor | 7 | 8 |

## Run it locally

1. Download `index.html`.
2. Open it in any modern browser.

That's it. The whole game is one HTML file.

## Built with

Plain HTML5 Canvas, vanilla JavaScript and the Web Audio API. No libraries or external assets.
